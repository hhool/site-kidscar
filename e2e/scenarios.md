# E2E Scenario Draft

## Scenario 1: From Home To Detail

1. Open home page
2. Click a stroller item
3. Verify detail page loads
4. Verify source fields are visible

## Scenario 2: Add To Compare And Inspect

1. Select two stroller items in the list
2. Open compare page
3. Verify key fields render side-by-side
4. Verify conclusion block includes strengths and weaknesses

## Scenario 3: Multilingual Consistency

1. Open Chinese detail page
2. Switch to English
3. Verify title, summary, and scoring sections are present in both languages
